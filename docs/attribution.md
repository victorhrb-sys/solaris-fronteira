# Origem e recursos

Solaris Fronteira é um projeto independente inspirado em
[Solaris](https://github.com/solaris-games/solaris), sem afiliação com seus autores.
A documentação anterior do projeto registra uma implementação própria de
interface e regras; esta distribuição contém os módulos do projeto e seus dados
de mapas, sem imagens, áudio ou componentes importados do jogo de referência.

O mapa, as estrelas e a interface são desenhados em HTML, SVG e CSS. Não há pacotes
de sprites, fotografias, música ou fontes binárias nesta distribuição.

`public/style.css` solicita **Chakra Petch** pelo Google Fonts. A fonte é de The
Chakra Petch Project Authors e usa
[SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/chakrapetch/OFL.txt).
Ela não é copiada para este repositório; o CSS já possui alternativas locais caso
a requisição externa não esteja disponível.

O publicador não atribuiu uma licença nova ao código do projeto nesta revisão.
A disponibilização do código não deve ser apresentada como uma escolha de MIT,
GPL ou outra licença que o responsável ainda não fez. As licenças de ferramentas
instaladas separadamente continuam pertencendo aos respectivos projetos.

Arquivos do starter da hospedagem, dependências vendorizadas, dados de sessões e
documentação privada de migração ficam fora da distribuição pública.
